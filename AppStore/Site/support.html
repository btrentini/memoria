Memoria

Memoria support

Memoria is a local system monitor for Apple Silicon Macs running macOS 26 or later.

Missing readings

Allow two consecutive samples for CPU and traffic rates. After sleep or a counter reset, Memoria starts a new interval. Macs without an internal battery show no battery reading. A missing value is not a measured zero.

Widgets

Enable aggregate widget sharing in Settings and keep Memoria running. Add the widget using macOS. The timestamp tells you when the sample was captured; macOS controls refresh timing. If sharing is disabled, the cache is deleted and the displayed widget updates when macOS next refreshes it.

Edition scope

The App Store edition shows system readings. Process resource lists, termination, Free Port, administrator features and private sensors belong to the separate direct-distribution development edition.

Report a problem

Use the project issue tracker. Include the Memoria version, macOS version and concise reproduction steps. Do not include credentials, process dumps, personal paths or unrelated screenshots.
