# App Store screenshots

Capture the actual signed, tested App Store edition. Do not use mock-ups, the icon proof sheet, the direct-distribution process manager or fabricated telemetry as screenshots.

Use one consistent Mac size: **1440 × 900 pixels**, RGB PNG/JPEG without alpha (Apple also accepts 1280 × 800, 2560 × 1600 and 2880 × 1800). Supply between one and ten screenshots. Suggested set:

1. Overview with a real CPU chart and the Simple control.
2. Memory view with components and the accounting explanation.
3. Interface traffic view, after checking that interface labels reveal nothing private.
4. Menu-bar popover and the enabled desktop widget, with their real timestamps.

Review the entire image for unrelated windows, names, paths or identifiers before publication. `Preview-Overview.jpg` is a real 1280 × 800 RGB capture of the local sandboxed preview, reviewed for unrelated windows, PIDs and private information. It demonstrates the current interface and live aggregate readings; replace or reconfirm it against the final signed build before submission. Widget and other-view captures remain pending.
